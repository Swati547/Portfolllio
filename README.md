# Frontend Project

## Overview
A frontend project containing HTML, CSS, and JavaScript files.

## Project Structure
- **index.html** - Main HTML file
- **index1.html** - Additional HTML file
- **style.css** - Main stylesheet
- **style1.css** - Additional stylesheet
- **script.js** - Main JavaScript file
- **script1.js** - Additional JavaScript file

## Getting Started
1. Open `index.html` in your web browser
2. Check the console for any JavaScript logs or errors
3. Review the stylesheets and scripts to understand the project structure

## Files Description
- HTML files contain the page structure
- CSS files handle styling and layout
- JavaScript files contain interactive functionality

## Notes
- Ensure all files are in the same directory for proper linking
- Update file paths in HTML if files are reorganized
